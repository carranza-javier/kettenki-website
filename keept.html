KeepT

Übersetze jeden Text auf deinem Bildschirm mit einer Taste

Drück F1: KeepT friert den Bildschirm ein, liest den Text und legt die Übersetzung direkt über das Original, an derselben Stelle. In jeder App, auch in Bildern, gescannten Dokumenten und Remotedesktops. Kostenlos und Open Source.

Für Windows herunterladen

Windows 10 oder 11, 64 Bit, rund 50 MB. Auf GitHub lädst du aus der neuesten Version die Datei KeepT-Setup mit der Endung .exe herunter. Installiert ohne Administratorrechte.

Quellcode auf GitHub

Pre-Release, noch nicht signiert

KeepT ist in Version 0.9 und noch nicht stabil. Die Version 1.0.0 wird die offizielle Veröffentlichung, dann mit signiertem Installer.

Bis dahin zeigt Windows SmartScreen möglicherweise die Meldung "Der Computer wurde durch Windows geschützt". Klicke auf "Weitere Informationen" und dann auf "Trotzdem ausführen". Der Installer wird von GitHub Actions direkt aus dem öffentlichen Repository gebaut, und jede Version nennt ihre SHA-256-Prüfsumme zum Vergleichen.

Was KeepT kann

  • Gemischte Sprachen: KeepT erkennt die Sprache jedes Textblocks und übersetzt alle auf einmal, etwa eine englische Seite mit einer deutschen Stellenanzeige darin.
  • 8 Sprachen in jede Richtung: Deutsch, Englisch, Französisch, Italienisch, Spanisch, Portugiesisch, Niederländisch und Polnisch.
  • Überall auf dem Bildschirm: in Programmen, Bildern, gescannten Briefen, Remotedesktops und virtuellen Maschinen.
  • Zum Sprachenlernen: Halte die Leertaste gedrückt, und das Original erscheint wieder zum Vergleich.

Hast du jemals F1 gedrückt, um Hilfe zu bekommen? Wir auch nicht. KeepT gibt dieser Taste endlich etwas zu tun.

Alles bleibt auf deinem PC

Bildschirm, erkannter Text und Übersetzungen verlassen deinen Computer nie. Es gibt kein Konto, keinen API-Schlüssel und keine Telemetrie.

Ins Internet geht KeepT nur für zwei Dinge: um die Übersetzungsmodelle einmalig von GitHub herunterzuladen, und, wenn du es nicht ausschaltest, um einmal am Tag nach einer neuen Version zu schauen.

Lizenzen

Die Übersetzungsmodelle stammen aus OPUS-MT von Helsinki-NLP an der Universität Helsinki und stehen unter der Lizenz CC BY 4.0. Für KeepT wurden sie nach CTranslate2 (int8) konvertiert.

KeepT selbst steht unter der MIT-Lizenz.
